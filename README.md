TWRP Device Tree for OPPO A31 (CPH2015)
===========================================

The OPPO A31 is a budget-friendly smartphone from OPPO, announced in February 2020.

**Working**:
1. MTP
2. Backup and Restore
3. Flash GSI
4. Screenshots
5. Decryption
6. OTG
